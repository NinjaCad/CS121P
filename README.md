# CS121P Portfolio (Fall 2025)

A small portfolio of **TMU CS121P** homework assignments written in **Python**.

## How to run
Most files are standalone scripts.

```bash
python Homework00.py
```

Notes:
- Assignments that use **turtle** will open a graphics window; close it (or click it) as instructed in the program output.
- `Homework08.py` reads `classes.txt` and writes `students.txt`.

## Repository contents (file-by-file)

### Assignments
- **`Homework00.py`** — Prints “Hello, World!”.
- **`Homework01.py`** — Prints an ASCII-art “TMU”.
- **`Homework02.py`** — Converts kilograms to pounds and ounces (interactive input).
- **`Homework03.py`** — Turtle graphics spiral/pattern based on user-provided angle and range.
- **`Homework04.py`** — Turtle graphics: draws multiple rotated polygons on a randomized background color.
- **`Homework05.py`** — Prints a text-based circle of `*` characters for a given radius (loops until radius 0).
- **`Homework06.py`** — Simple mad-lib generator using placeholders of the form `(^ ... ^)` and random selection from user choices.
- **`Homework07.py`** — L-system generator and turtle renderer (rules defined in the script; draws the resulting fractal).
- **`Homework08.py`** — Processes **`classes.txt`** into a student→classes mapping and writes **`students.txt`**.
- **`Homework09.py`** — Implements `Fraction` and `MixedFraction` classes with arithmetic and comparison operators; includes a `main()` demo.

### Data / reference files
- **`classes.txt`** — Input data for `Homework08.py` (classes and enrolled students).
- **`students.txt`** — Output produced by `Homework08.py` (students and their classes).

### Other
- **`CS121P Homework Assignments.pdf`** — Assignment handout/reference document.

## Overview
This repo is organized as one script per homework assignment (`Homework00.py` … `Homework09.py`). Each script demonstrates a specific concept covered in an introductory programming course (console I/O, math, loops, file I/O, basic classes/operator overloading, and turtle graphics).
